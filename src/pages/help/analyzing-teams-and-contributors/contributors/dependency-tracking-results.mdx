# Dependency Tracking Results

![General Settings Landing Page](/help/dependency-contributor.png)

The dependency tracking result page for a contributor showcases all repositories we've analyzed, indicating which ones have a match with your dependency and whether they are active or not.
If a project is inactive, we further analyze the contributors to identify other relevant repositories. This page provides a comprehensive list of the projects we've analyzed, offering insight into why we concluded a contributor is inactive or active. You can directly add repositories found here to a list or utilize the [boosting feature](help/finding-projects/boost) to automatically include all repositories actively using your dependency.
