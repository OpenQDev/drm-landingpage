# Repo Commit Summary

![AI Report](/help/contributor-progress-report.png)

Repository commit summaries provide an overview of the commit messages made in the past weeks. These summaries are valuable for understanding recent developer activities and identifying relevant commits for your technology. We are continuously improving this feature and currently exploring methods to offer message templates, facilitating more engaging interactions with developers.

## How to Generate a Report

![AI Report How To](/help/ai-report-how-repos.png)

To generate a report, you can either navigate to the repository's commit view and select "Summary," or visit the dedicated page of the repository within the report section.
