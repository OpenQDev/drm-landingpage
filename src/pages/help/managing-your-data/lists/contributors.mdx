# Contributors

![Contributors](/help/contributor-page.png)

In the contributors tab, you'll discover all GitHub users you've included, along with contributors from repositories and organizations we added automatically.

## Table Data

- **Name**: Name of the user
- **Dependencies**: Indicates whether the contact utilizes your dependency in their project.
- **Email**: Email found within commit message or from the profile.
- **Description**: User profile description.
- **Location**: Location of the user.
- **Latest Commit**: Date of the last commit.
- **Social**: All social media accounts found from GitHub.
- **Activity**: Activity score of the contributor on GitHub. [Here](/help/managing-your-data/campaigns/metrics#user-activity-score) is an overview how we calculate it.
- **Top Languages**: Common programming languages used in their projects
- **Reputation**: Reputation score based on stars, followers, and forks of all repos commited or created. [Here](/help/managing-your-data/campaigns/metrics#user-reputation-score) is an overview how we calcuate it.
- **Commits**: Total number of commits the user made in the last 6 weeks.
- **Stars**: Number of stars the user has across all repositories
- **Followers**: Number of followers the user has.
