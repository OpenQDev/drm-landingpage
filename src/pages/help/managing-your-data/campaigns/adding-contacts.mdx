# Adding contacts

In the context of our platform, "Contacts" refers to GitHub users you are tracking via OpenQ. Does not exclude inactive or cold developers.

![add-contacts](/help/add-contacts.png)

You can include contacts in each campaign either by [importing them from a CSV file](http://openq.dev/help/imports-and-exports/import-data-into-openq-via-csv) or by adding them manually. Make sure to include full GitHub links and not handles when adding contacts.

![add-contacts](/help/add-contacts-2.png)

## Including Repo Contacts

To filter your added contacts and manage a list of links that might not be well-curated, you can enable repo contacts. This feature will add all repositories to the campaign, which is useful if you have a mixed list of repositories and users and want to exclude repositories.

## User/Org Contacts

To filter your list of contacts and include users and organizations, check this box. If unchecked, it will exclude users and organizations from your list.

## Full Org

OpenQ does not automatically clone all repositories or contributors within an organization. If you want to include all repositories and contributors from an organization, check this box. Note that this option only works for one organization at a time and cannot be used for a large number of organizations simultaneously.
