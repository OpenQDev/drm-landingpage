# Teams

![Teams](/help/team-page.png)

Within the Teams tab, you can find all GitHub repositories and organizations you've added to the campaign. All contributors within these repositories and organizations are automatically added to the [contributors](/help/managing-your-data/campaigns/contributors) tab, eliminating the need for manual addition.

## Table Data

- **Owner**: Indicates whether the contact is a GitHub organization or repository. Organizations can be accessed via a dropdown.
- **Name**: Name of the repository or organization.
- **Dependencies**: Indicates whether the contact utilizes your dependency in their project.
- **Description**: Description of the project.
- **Latest Commit**: Date of the last commit.
- **Social**: All social media accounts found from GitHub.
- **Activity**: Activity score of the repository or organization.
- **Languages**: Programming languages used in the repository.
- **Reputation**: Reputation score based on stars, followers, and forks of contributors.
- **Popularity**: Popularity score based on stars, watches, and fork counts of the repository.
- **Commits**: Number of commits in the repository in the last 6 weeks.
- **Stars**: Number of stars the repository has.
- **Recent Contributors**: Most recent contributors.
